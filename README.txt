SASHA | Sport Diary — автономное веб-приложение (PWA), не APK.
Для установки на Android разместите содержимое папки на HTTPS-хостинге, откройте адрес в Chrome и выберите «Установить приложение» или «Добавить на главный экран».
Для локального предварительного просмотра: откройте index.html в браузере. При открытии с file:// офлайн-кеширование может быть недоступно.
Данные хранятся в localStorage браузера. Очищение данных браузера удалит записи — регулярно экспортируйте резервную копию в настройках.
PDF создаётся через системную функцию «Печать → Сохранить как PDF».
